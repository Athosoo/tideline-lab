# CLOUD LAB · 前端体积云实验室

一个**零依赖**的单文件 WebGL2 体积云实验台。双击 `index.html` 就能跑，不需要服务器、不需要构建、不需要联网。

目的：把"天上那层扁平贴片"换成真正的**体积云**，并把**云和海/地平线的衔接**调到自然。

---

## 1. 算法结构（Nubis 三段式）

```
密度 = 云体形状 × 天气覆盖 × 高度剖面
颜色 = 太阳单次散射(相函数 × 自阴影) + 天空环境光 → Beer-Lambert 累积 → 逐样本空气透视
```

| 阶段 | 做法 |
|---|---|
| 几何 | 地球球壳求交（R=6371 km），云层为 base–top 之间的球壳，射线自然向地平线收敛 |
| 密度 | 4 octave 3D FBM（64³ 运行时生成）× Worley 细胞噪声（32³，团块感）× 高度剖面 |
| 覆盖 | 天气噪声阈值 = `0.385 + (0.5 − coverage) × 0.30`，再平方锐化（阈值必须按噪声真实分布标定） |
| 光照 | 太阳方向 if 6 步自阴影 + Henyey-Greenstein 双叶相函数（0.62 / −0.26）+ powder |
| 累积 | 前向 alpha 合成，`σ = 密度 × 0.0012`，步长近密远疏（前 14 km 均匀，其余等分） |
| 空气透视 | **逐样本** `mix(color, haze, 1 − exp(−距离 × 2.4e−5))` |
| 海面 | 解析平面 + Fresnel + 太阳耀斑 + 云层反射（同一条 march 的镜像） |

## 2. 为什么"云和海衔接突兀"（关键结论）

硬切的根因不是云，是**缺少统一的距离雾**。修复要点：

1. **天空、云、海三者必须收敛到同一个雾色**，且雾强度随距离连续增长；
2. 海面的雾用 `1 − exp(−距离 × k)`；距离在地平线处 → ∞，自然饱和成雾色；
3. 天空用 `1 − exp(−pow(rd.y, −0.9) × 0.055)`（天顶几乎无雾，贴着地平线迅速饱和）；
4. 云的雾**逐样本**做，不要只在最后统一混一次——这样远处云自己就"化"进地平线里了。

面板上的 **AERIAL 开关**就是用来对比的：关掉立刻能看到硬边。

## 3. 交互

- 拖动画面：转头；滚轮：变焦
- 三个预设：`CUMULUS` / `STRATUS` / `STORM`
- 关键参数：COVERAGE（云量）、DENSITY（厚度）、DETAIL EROSION（边缘侵蚀）、
  CLOUD BASE/TOP（云层高度）、MARCH STEPS / LIGHT STEPS（性能与质量）、RENDER SCALE（分辨率）

## 4. 调试模式（URL 参数）

| 参数 | 作用 |
|---|---|
| `debug=1` | 固定高度切片的密度场（看云的分布结构） |
| `debug=2` | 云的不透明度（黑白） |
| `debug=3` | 密度和 / 峰值 / alpha |
| `debug=5` | 忽略噪声，用恒定密度测试 march 本身 |

其它：`preset=` `steps=` `light=` `scale=` `coverage=` `density=` `detail=` `base=` `top=`
`wind=` `sunEl=` `sunAz=` `haze=` `pitch=` `yaw=` `aerial=0/1` `reflect=0/1`

## 5. 性能

云端 march 的成本 ≈ `步数 × (密度采样 + 自阴影采样)` 次 3D 纹理读取。
实验室默认 `64 / 6 / 0.75`，桌面独显 1080p 一般在个位数毫秒；弱机把 STEPS 降到 24–32、
RENDER SCALE 降到 0.5，或直接用 STRATUS 预设。

> 注意：无头 Chrome 用的是 SwiftShader 软件光栅，帧时间没有参考价值，真机请直接看左上角 `frame`。
